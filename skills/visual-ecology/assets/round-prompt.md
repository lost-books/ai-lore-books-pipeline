# Visual Ecology round prompt

Run a Visual Ecology image round for the book below.

First read the manuscript as reference material. Then write exactly [COUNT, default 8] numbered treatment briefs. Each brief must state the conceptual function, subject or visual event, actual medium or physical process, style or era where useful, composition or scale, palette and emotional temperature, and orientation. Include tall unlettered cover candidates in every round: one for a one- or two-image round, at least two when the count permits. Apply these bans: [BANS OR NONE]. Apply this round direction: [DIRECTION OR EXPLORE BROADLY].

Create a genuinely varied set. Vary media and processes, but allow a repeated medium when two strong concepts need it and differ substantially in subject, composition, and emotional effect. Make every pair differ in at least two other ways, such as subject type, era, scale, composition, spatial logic, palette, literalness, or emotional temperature. Vary the imagined human hand and material history. Avoid nominal media changes that still produce the same photographic or digital aesthetic.

Pictorial, directly illustrative scenes are welcome when they carry the manuscript's tension. Avoid decorative random weirdness, generic ominous imagery, and bland, cute, reassuring stock illustration. Do not default to conventionally pretty polished people or repeated tidy hairstyles. Expand the book's world rather than illustrating each paragraph.

Present the briefs and stop for selection and steering. After approval, generate exactly one separate image per approved brief, one at a time, in order. Present small batches as they complete. Label each image with a stable round number and short name. Put functional Approve, Reject, and separate Mark as cover controls with each image, using a local HTML review page backed by a saved decision ledger if chat controls cannot persist clicks. Record plain numbered feedback in the same ledger. Do not create a contact sheet. Use no title lettering, text overlays, logos, or watermarks. Preserve every generated variant and use stable numbered filenames when files can be saved. Marking as cover neither approves the image nor excludes interior use.

Keep all later rounds and replacements for this book in this same conversation. Remember previous subjects, media, palettes, compositions, approved images, rejected images, and bans so later rounds do not repeat them.
